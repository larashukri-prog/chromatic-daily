## Reset the preview

The app already has a built-in reset. Open the preview at:

`/?reset`

(e.g. append `?reset` to the current preview URL and load it)

This clears the daily local-storage state, wipes today's attempts, and returns you to Attempt 1 / Stage 1 so you can test the puzzle across Colors, Patterns, Shapes, and MTA themes.

No code changes required — this is a usage instruction.
